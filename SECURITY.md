# Security Policy

This repository publishes a static research and documentation site.

## Reporting a security or privacy issue

If you find a credential, secret, personal information, or other content that should not be public, do not open a public issue containing the sensitive material. Contact the repository owner privately through the organization or maintainer contact channels.

## Repository hygiene

Do not commit:

- passwords, API keys, tokens, or connection strings;
- private keys or certificates;
- private customer or company data;
- environment files containing credentials;
- internal-only architecture or operational details unless intentionally approved for publication.

GitHub Actions used for publishing should use least-privilege permissions and pinned action revisions.
