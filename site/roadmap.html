Roadmap & Decisions

Current direction

Build the contracts before multiplying the products

The roadmap prioritizes shared semantics—identity, control, evidence, taxonomy, and product contracts—before deeper autonomous runtimes.

Phase 1Binder v0.1

Product manifest, entity IDs, namespaces, evidence references, ownership semantics, compatibility.

Phase 2Batchbook / Batch / Swatch

Minimum graph, canonical entities, ownership, classifications, profiles, decks, palettes.

Phase 3Snitch + Teardown

Observation schema, topology, Genealogy, reconciliation, confidence, source precedence.

Phase 4Controls + Proof

Control schema, profiles, exceptions, evidence basis, assurance, Stamps, CoA.

Phase 5Crosslink + lifecycle

On-call, escalation, incident coordination, retirement, Reclaim, feedback loops.
