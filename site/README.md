# AI SDLC Governance Site

Static, dependency-free site generated from the working AI SDLC Governance Family notebook.

## Run locally

Open `index.html` directly in a modern browser.

For the cleanest local experience, you can also serve the folder:

```bash
python -m http.server 8080
```

Then open `http://localhost:8080`.

## Structure

- `index.html` — start here
- `governance.html` — governance model
- `family.html` — product family
- `information-model.html` — Batchbook / Batch / Swatch and graph model
- `deployment.html` — execution models and Shearing Layers
- `adoption.html` — taxonomy, vocabulary, compliance profiles
- `proof.html` — evidence, assurance, Stamps, CoA, Notary/Witness
- `history.html` — governance side quest
- `roadmap.html` — decisions and next steps
- `INFORMATION_ARCHITECTURE.md` — site IA
- `styles.css` / `app.js` — shared presentation and behavior

The site intentionally reorganizes the notebook by durable concepts rather than reproducing the notebook's chronological sections.
