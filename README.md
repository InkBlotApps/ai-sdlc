## Core idea

> **Governance is the system that makes organizational intent operable.**

The family is designed around a few durable ideas:

- governance should be proportional rather than binary;
- organizations should be able to use their own vocabulary while sharing canonical meaning;
- deterministic controls should remain deterministic;
- agents should operate with bounded delegated authority rather than becoming the system of record;
- evidence basis, confidence, and assurance should remain separate;
- fast-changing layers should be able to learn without destabilizing slow-changing contracts.
